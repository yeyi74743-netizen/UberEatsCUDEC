# YEYIFOOD

## Descripción

YEYIFOOD es una aplicación web para administrar
platillos y pedidos de manera sencilla y organizada.

## Objetivo

Facilitar la gestión de platillos y pedidos,
reduciendo la desorganización y los procesos manuales.

## Funciones

- Administración de platillos.
- Registro y consulta de pedidos.
- Organización de información.
- Diseño adaptable a dispositivos móviles.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Materialize CSS

## Problemas que atiende

YEYIFOOD ayuda a solucionar problemas como la
desorganización de pedidos, pérdida de información
y dificultad para llevar un control de los platillos.

## Desarrolladores

Proyecto académico de desarrollo web.
